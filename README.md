# randomized-pca

Benchmarking randomized PCA stability and downstream effects in single-cell RNA-seq analysis

## Overview

This benchmark was created using [OmniBenchmark](https://omnibenchmark.org) v0.6.0, a framework for automated scientific benchmarking.

## Getting Started

1. Install OmniBenchmark:
   ```bash
   pip install omnibenchmark
   ```

2. Run the benchmark:
   ```bash
   ob run benchmark.yaml
   ```
